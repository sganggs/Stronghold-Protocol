# Formation profile tools

Run node tools/layout-lab/learn.mjs to regenerate server/match/botFormationProfiles.js from the committed anonymous demonstrations. Example six of each map is held out. Run node tools/layout-lab/evaluate.mjs to compare layout geometry on those examples.

model.mjs validates explicit imports from local annotations; no annotation UI is included in this proposal. See [scope and evidence](../../docs/research/ioleta-adaptive-default.md).
