# 战斗中查看队友与 Boss 另一组

普通战斗尚未结束时，可以查看现存队友战场；最终攻势和隐秘核心可以查看另一组，并返回自身。重连恢复普通／Boss／隐秘核心的已选视图。

这是显示副本切换：自身权威战斗继续运行，g.watch 不转移 authority，不改伤害、LP、奖励或结算，不额外返回手牌和资金。淘汰／退出队友、无效字段、战斗期间不存在的准备阵地仍拒绝。联防旧普通阵地的保留／回看不属于本补丁。开发页面的镜像拒绝规则一并移除。

关联 [#967](https://github.com/sganggs/Stronghold-Protocol/issues/967)。普通战斗开放是本项目拟采用的 QoL，不声称官服所有版本已有同样行为。

## 页面核验

在独立主线分支上用 Firefox 验证普通战斗、最终攻势和隐秘核心，覆盖 1280×720、960×540：点击队友“前往查看”、返回自身、服务端重连重发，以及重新挂载 GameScreen 后恢复返回入口。查看期间自身 authoritative 战斗时钟继续推进，队友副本 non-authoritative，返回不转移权限。

页面使用真实 Match 动作、b.start／重连消息与默认浏览器 runner；截图使用默认二期数据；初始四人名单及阶段是受控夹具，通过 HTTP 动作桥接，不能当作完整 WS／Worker 对局或完整模拟／golden。夹具校准虚拟调度与页面时钟，并等待开场提示退出后截图。无新增控制台错误或 HTTP 失败；保留在干净 dev 同样可复现的 data-URL CSP 诊断，未为截图放宽 CSP。
