# 移动召唤者后保留合法召唤物

来源为用户官服实测录像《明日方舟 2026-11-12 01-00-52.mp4》。该文件是本机提供的原始证据；公开录像链接和关键时间另随 PR 补充，不将本机 file URL 当作维护者可访问的链接。

准备阶段普通移动或交换位置，在双方最终位置确定后检查原召唤物是否仍处于合法地块和范围内；合法者保留实例、朝向、数量，非法者沿既有路径退回召唤堆叠。不限范围的支援装置保持原位；战术点仍受所属干员的最终攻击范围约束。

本改动不改变召唤物部署范围或战斗 kit，不扩大撤退、出售、晋升、地形变化的规则。各版本共用准备逻辑，新的保留行为依据是这份新版官服录屏，不声称逐个复测过历史客户端。PRTS 帮助曾记载全部召回的旧行为，不能用作本次保留规则的新证据。
