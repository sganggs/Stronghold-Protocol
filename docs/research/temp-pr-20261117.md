# 临时盟约层数的显示链路

临时层数仅在本场战斗显示：永久 100＋临时 20 显示黄色合计 120，盟约栏与详情一致；准备、结束和切场后清除临时标记。

InPageSimHost 订阅 `tempLayerGain` 实际增量收据，Worker 包单独携带 `tempBondLayers`，runner 发布不可变的 `bondTempLayers`。有临时加成的永久基数锚定当前战斗，避免较新的结算视图把转永久收益再加一次。不改 Battle、结果、RNG、发放或转换规则，也不新增服务器战斗事件。

玩法生产端依赖 [#962](https://github.com/sganggs/Stronghold-Protocol/pull/962) 的 `tempLayers`／`tempLayerGain`。本补丁不复制该 PR 的玩法实现；旧生产端没有收据时不伪造临时层。展示单元用明确的事件夹具检查消费者，组合验证另使用 #962 的真实生产端。Boss／联防只显示生产端本来就发出的战内收据，不把它们改为可结算收益。

显示口径来自用户官服观察；不新增三期发放或数值假设。
