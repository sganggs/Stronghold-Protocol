### 27.1 The battle sim computes with engine-independent math (PR #373 by @Cloudnyco) — `server/sim/detmath.js` (new), every sim `Math.hypot / sin / cos / atan2 / pow` call
- **Seen**: ECMA-262 lets `Math.hypot`, `sin`, `cos`, `atan2` and `pow` return implementation-approximated values, and
  the engines differ in the last bits (V8's hypot is not SpiderMonkey's or JavaScriptCore's; Chrome 154's sin / cos /
  atan2 are correctly rounded while Node's are fdlibm's; JavaScriptCore computes integer powers by repeated squaring).
  A battle simulated in Firefox or Safari could therefore drift from the server's verification run.
- **Now**: `detmath.js` builds `hypot` (√(x² + y²), rescaled by exact powers of two outside 2^±500), `powi` (integer
  powers in double-double, one final rounding), `sin` / `cos` (fdlibm 5.3) and `atan2` (fdlibm / FreeBSD msun) only from
  correctly rounded IEEE operations, so every conforming engine gives the same bits. sin / cos / atan2 are the
  algorithms V8 already runs in Node, so the server's results stay; ESLint forbids the approximated Math functions
  under `server/sim/` and `test/sim/detmath.test.js` scans for them.
- Golden: two scenarios move, both by `hypot` — diy-027 (one distance, damage +80) and coop3-ABYSS-5 (a later card pick
  from round 9, same end). Tests: detmath 7; the whole suite unchanged otherwise.

### 27.2 Windows CI: UTF-8 zip entry names (PR #311 by @Cloudnyco, merged on master with the owner's OK) — `tools/package.mjs zipFolder`, `tools/package-update.mjs readZip`
- **Seen**: since 0.2.1 one test failed on both Windows CI legs of every PR and of master: the GitHub Windows runners
  have no `zip`, the fallback bsdtar wrote 卫戍 in the system code page (`??`) and the update tool's reader decoded only
  UTF-8. No shipped file has a non-ASCII name, so players and the release zips were never affected.
- **Now**: bsdtar is told `--options zip:hdrcharset=UTF-8`; the reader also takes Info-ZIP's Unicode Path extra field
  (0x7075) when its CRC matches the header name. PR #363 (relax the assertion) was closed as superseded.

### 27.7 伊内丝 S3 starts again on a 突袭 landing (community report) — `sim/battle/deploy.js _deploy` (keepSp)

  to keep; the redeploy is a deployment.
